# ASO Screenshot Studio: файлова структура

Цей документ описує заплановану структуру нового інструмента за [TZ.md](./TZ.md). Файли-заготовки створені порожніми; опис нижче визначає їхнє призначення, а не готову реалізацію.

## Інтеграція із сайтом

ASO Screenshot Studio відкривається на `/aso-screenshot-studio`: тут розташовані список локальних проєктів і стартові шаблони. Редактор конкретного проєкту відкривається на `/aso-screenshot-studio/editor?project=<id>`. Посилання зі StudioHub веде до списку.

```text
app/
  aso-screenshot-studio/
    page.tsx                         # Список проєктів і вибір старту
    editor/page.tsx                  # Редактор конкретного проєкту
  api/
    aso-screenshot-studio/
      localize/
        route.ts                     # Серверний маршрут локалізації

features/
  aso-screenshot-studio/
    components/
      AsoScreenshotStudio.tsx        # Кореневий компонент редактора
      home/                          # Список проєктів і створення з шаблону/копії
      toolbar/                       # Дії проєкту, групи, zoom, undo/redo
      sidebar/                       # Каталог тексту, пристроїв, зображень, фігур
      workspace/
        GroupCanvas.tsx              # Композиція групи
        SlideViewport.tsx            # Область слайда з обрізанням вмісту
        SelectionOverlay.tsx         # Рамки вибору й маніпулятори
        SnapGuides.tsx               # Візуальні напрямні
      inspector/                     # Властивості поточного вибору
      preview/                       # Нижня панель мініатюр активної групи
      dialogs/                       # Створення, локалізація, налаштування ключа
    domain/
      schema.ts                      # Типи та версія Project/Group/Slide/Element
      commands.ts                    # Структуровані дії редактора
      geometry.ts                    # Координати, gap, перетини, ownership
      snapping.ts                    # Пошук точок прив'язки
      slides.ts                      # Вставка, видалення, зміна порядку
      localization.ts                # Сегменти rich text і ручні переноси
      presets.ts                     # Розміри App Store / Google Play
    render/
      scene.ts                       # Спільна модель сцени
      slide.ts                       # Рендер окремого слайда з clipping
      svg.ts                         # Основа для полотна, preview та PNG
    hooks/
      useStudioProject.ts            # Стан проєкту та застосування команд
      useSelection.ts                # Вибір і мультивибір
      useHistory.ts                  # Undo/redo логічних операцій
      useWorkspaceZoom.ts            # Масштаб і позиція видимої області
    services/
      projectFiles.ts                # Імпорт/експорт JSON, перевірка версії
      projectStore.ts                # Множина локальних проєктів у localStorage
      templateCatalog.ts             # Каталог готових JSON-шаблонів
      assetStore.ts                  # Користувацькі зображення та посилання
      exportPng.ts                   # PNG у фактичному розмірі слайда
      exportZip.ts                   # ZIP із PNG усієї групи
      localizationClient.ts          # Запит локалізації з UI
    server/
      localization.ts                # Виклик OpenAI та перевірка відповіді
      prompts.ts                     # Англомовні промпти для ASO-перекладу

public/
  aso-screenshot-studio/
    templates/                        # JSON-шаблони та index.json
    devices/                          # Підготовлені 2D мокапи та маски екрана
    decorations/                      # Декоративні ресурси бібліотеки
```

У каталогах, для яких ще не визначено конкретних компонентів або ресурсів, лежать порожні `.gitkeep`. Вони потрібні лише для збереження структури в Git.

## Межі модулів

- `domain/` містить серіалізовану модель і чисті операції. `Element` належить `Group`, а `Slide` визначає область перегляду й експорту. Координати зберігаються у фактичних пікселях групи.
- `render/` використовує одну модель сцени для редактора, мініатюр і експорту. Кожен слайд обрізає композицію до своїх меж, тому в проміжку `gap` вміст не з'являється. Zoom змінює лише відображення.
- `components/` відповідає за взаємодію. Зміни проєкту проходять через `domain/commands.ts`, щоб Undo/Redo та майбутній MCP використовували ті самі дії.
- `services/` відповідає за файли, користувацькі ресурси та експорт. JSON зберігає посилання на screenshots, а не binary/base64. Для відсутніх ресурсів після імпорту потрібен placeholder і повторне завантаження.
- `server/` і маршрут `localize/route.ts` відповідають лише за локалізацію. Введений користувачем OpenAI ключ має передаватися на час запиту; він не входить у JSON проєкту. Модальне вікно дозволить змінити ключ і модель. Англомовні промпти мають пояснювати контекст ASO та зберігати ID форматованих сегментів і явні переноси.

## Порядок реалізації

1. Модель JSON, команди, геометрія слайдів та базова сторінка редактора.
2. Полотно, вибір, Inspector, історія та узгоджений рендер.
3. Типи елементів, бібліотека пристроїв, користувацькі ресурси.
4. JSON import/export, PNG/ZIP і preview.
5. Локалізація з вибором моделі та власним ключем користувача.

Перед наповненням бібліотеки пристроїв слід визначити формат 2D мокапів і масок. Перед збереженням користувацьких ресурсів — поведінку цих ресурсів після перезавантаження сторінки. Решта відкритих питань перелічена в `TZ.md`.
